How it works

Three rules. That's it.

01

Follow the arrows.

Each arrow points where the path must go next. Misread one and the path breaks.

02

Cover every cell.

The path has to pass through every square on the board. No shortcuts, no leftovers.

03

Find the exit.

One way in, one way out. Trace the only path that satisfies both, and the puzzle opens.
